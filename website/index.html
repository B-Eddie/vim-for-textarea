QUESTIONS

Which sites does it work on?

Any page with a textarea, text input, or contenteditable element. GitHub, Gmail, Notion, Linear, docs, forms, and web IDEs all work.

Can I turn it off for specific sites?

Yes. Toggle the current site from the popup, or add blacklist patterns such as *.google.com for places where Vim should never activate.

Can I change the key bindings?

Yes. Open the Motions Editor from the popup to remap bindings, operators, text objects, and commands with live validation.

What permissions does it need?

Storage first. It saves your settings, theme, blacklist, and custom bindings locally, with clipboard and tab access for paste and per site state.

Is it free and open source?

Yes. The code is public on GitHub and contributions are welcome through issues and pull requests.
